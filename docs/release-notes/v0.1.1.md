## Auto-Exit v0.1.1

Maintenance release. The Windows installer picks up two wallet-import UX fixes; the rest are infrastructure improvements (self-hosted Docker stack, hardening, multi-platform install docs, RPC choice guidance) that don't change installer behavior.

### Changed (in this installer)

- **Wallet import errors are now actionable and non-leaking.**
  - Bad keypair bytes (Solana error #3704004) → "the private key bytes do not form a valid keypair" instead of cryptic SDK output.
  - Non-base58 characters (#8078012) → names the offending character with its Unicode code point and detects homoglyphs (Cyrillic letters that look identical to Latin ones — typically introduced by browser auto-translation).
- New `/docs/operational#rpc` section in-app — guidance for picking a private RPC (Helius free tier and alternatives) to avoid 429 rate limits when listing positions on Meteora.

### Repo-only (not in the installer)

- **Self-hosted Docker stack** — `docker compose up` now serves both server (`:7777`) and web (`:3000`) from a single image. See [ADR-036](https://github.com/pedrojorgelozano/Solana-Auto-Exit/blob/v0.1.1/docs/DECISIONS.md).
- **Docker stack hardened** — non-root user (uid 1000), read-only rootfs, dropped capabilities, no-new-privileges, resource limits, healthchecks. See [ADR-037](https://github.com/pedrojorgelozano/Solana-Auto-Exit/blob/v0.1.1/docs/DECISIONS.md).
- **Multi-platform install guide** — Windows / macOS / Linux instructions, with Docker and "Run from source with pnpm" paths. The latter is the recommended path for hardened hosts (strict firewall + kill-switch VPN). See [INSTALL.md](https://github.com/pedrojorgelozano/Solana-Auto-Exit/blob/v0.1.1/docs/INSTALL.md).

### Updating from v0.1.0

- **Manual**: download and run this installer over the existing install. Your data folder at `%APPDATA%\com.autoexit.desktop\` is preserved.
- **Auto-update**: if you enabled "Check for updates" in /settings on v0.1.0, the app will prompt to update on next start. This is the first release that exercises the auto-update flow end-to-end — please open an issue if you hit any problem with the verification or install.
